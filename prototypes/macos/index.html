第二版交互规则

  1. 唯一搜索同时查本地和网络，同一首歌优先本地播放。首页是私人 FM、歌单电台、关注艺人的新作和最近保存的本地歌曲。
  2. 本地歌单只有本地曲目，以 M3U8 保存。远程歌单单独分组，可在设置中显示／隐藏，两组可折叠。
  3. 加号默认加入当前播放的歌单，随后可更改目标。网络歌曲加入本地歌单先下载；临时播放列表可以新建保存。
  4. 完整在线播放一首才累计一次，默认 3 次自动保存，可在头像菜单的设置中调整／关闭。
  5. 下载入口随本次任务出现，完成后显示已下载；重新打开只恢复未完成任务，已完成的曲目仍留在本地资料库。

上方按钮模拟播放器与下载事件。示例设置、歌单、播放次数和本地收录情况只存于浏览器；不会修改正式 App 或真实音乐文件。真实账号与推荐接口尚未接入。
